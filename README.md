# НЕЙРОПОКЕР

Покер против алгоритма и самообучающейся нейросети, с полным обучением с нуля.

## Запуск

XML-контент загружается через fetch, поэтому нужен локальный сервер:

```bash
cd neuropoker
python -m http.server 8080
```

После чего запуск по адресу: http://localhost:8080/

Либо можно попытаться зайти на сайт: https://ntutugin-cyber.github.io/neuropoker/
